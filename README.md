# kaumono — 買うものリスト

日用品と食料の在庫台帳。**NFCタグを貼っておき、切れたその場でかざすと「欲しい」が立つ。**

家の消耗品が切れるのは、たいてい手が塞がっている瞬間（風呂場、調理中、詰め替えを
捨てる時）で、そこでメモを取れないから買い忘れる。タグをかざすだけで記録が終われば
その断絶が消える、という一点のための道具。

Flask 1ファイルのサーバと、素の HTML/JS が1枚。依存は Flask だけ。

## できること

- **NFCタグ**: タグに `/t/<好きな文字列>` を書いてかざすと「欲しい」が立つ。
  Android は既定ブラウザが勝手に開くので実質かざすだけ、iPhone は通知バナーを1タップ
- **貼ってから紐付ける**: 未登録のタグをかざすと紐付け画面が出る。何十枚も事前に
  採番して書き分ける必要がない（連番を書いておけばよい）
- **置き場所と種類の二軸**: エリア（どこにあるか）とジャンル（何か）は直交。同じ
  「掃除」でも洗剤はトイレ、別のは風呂に置いてある
- **買うものは通販サイトごと**にまとまる。注文はサイト単位で終わるので、
  Amazon の分・楽天の分と分かれていないと片づかない。束ごとに「全部開く」「全部買った」
- **購入履歴**: 買った日を積んで「前回◯日前・平均◯日おき」を出す。タグを触り忘れても
  そろそろだと分かるようにするための保険
- **URLの正規化**: 貼られた短縮リンクや追跡パラメータまみれのURLを
  `https://www.amazon.co.jp/dp/<ASIN>` のような素の形に均す（保存時 + 定期実行）
- ドラッグで並べ替え、ライト/ダーク

在庫の状態は **ある / 欲しい の2値**で、数量は持たない。数えるのは続かないため。

## 動かす

```bash
pip install flask
python3 seed.py          # 叩き台を入れる（空のまま始めてもよい）
python3 server.py        # http://0.0.0.0:8689
```

データは `$KAUMONO_DATA/stock.json`（既定 `~/kaumono-data/stock.json`）。
JSON 1枚なので、中身を見るのも別の場所へ移すのも簡単。

**認証は持たない。** 家庭内 LAN か VPN（Tailscale など）の中に置き、公開範囲は
ネットワーク層で絞る前提。タグに書く URL はシールの表面から誰でも読めるので、
秘密を置く場所ではない。

### 常駐させる

`systemd/kaumono.service` を雛形として使う。`KAUMONO_DATA` と各パスを自分の環境に
書き換えて `/etc/systemd/system/` に置く。

### URLの正規化を定期実行する

短縮リンク（`amzn.asia` 等）の解決にはネットワークが要るので、保存時ではなく
cron で回す。文字列だけで済む追跡パラメータ落としはサーバが保存時に行う。

```cron
40 4 * * * /usr/bin/python3 /path/to/kaumono/normalize_urls.py
```

## NFCタグ

NTAG215（504バイト）で十分。タグには URL を1本書くだけ:

```
http://<サーバのアドレス>:8689/t/01
```

連番でよい。初回にかざすと紐付け画面が出て、そこで品目を選べば以後そのタグは
その品目の「切れた」ボタンになる。書き込みは NFC Tools（Android/iOS、無料）などで。

タグの**書き込みロックは押さないこと**。不可逆で、二度と書き換えられなくなる。

貼る位置は品目ごとに考える。詰め替えを使うもの（シャンプー・洗剤）は**ボトルでは
なくストックの最後の1袋**に貼る。ボトルに貼ると「詰め替えたばかりで在庫ゼロ」を
検知できない。

## テスト

```bash
python -m unittest discover -s tests
```

ネットワークにも実データにも触らない。

## 制限

- **Amazon のカート一括投入は使えない。** `gp/aws/cart/add.html` は GET も POST も
  200 を返すがカートは空のまま（実機確認済み）。個人向けの注文APIは存在せず、
  Dash Replenishment も終了しているので、注文の自動化はできない。
  「全部開く」でタブを並べて人が確定する形が上限
- ブラウザは1回の操作につき1つしかタブを開かせない。「全部開く」は
  ポップアップ許可を出すまで1件しか開かない（塞がれた分は1件ずつ開くリンクが出る）
- 複数人が同時に触ると後勝ち。家庭内の規模を想定している
